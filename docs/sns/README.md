## 想定読者

- 学生（定期テスト、受験、大学の課題）
- 資格やスキルの勉強をしている社会人（簿記、基本情報技術者、TOEIC など）
- 個人開発者（開発過程に興味がある人）

## 投稿ルール

- **頻度**：機能が一つ完成したら投稿する。週1〜2回が目安で、ノルマは設けない
- **形式**：画像（スクショかGIF）1枚と短い文章。「何ができたか」と「学んだこと」を一言ずつ
- **ハッシュタグ**：`#個人開発` は毎回付ける。勉強寄りの内容なら `#勉強垢`、資格の話なら `#資格勉強` も付ける。合計2〜3個まで
- **文体**：です・ます調で統一する。言い切り（〜したい。）や体言止め（〜したもの。）を混ぜない。ハッシュタグとカギカッコ内の引用は除く
- **トーン**：勉強しながら作っている等身大の開発者として書く。誇張や煽りはしない
- **時期**：定期テスト前、受験期、資格試験の申込時期に合わせて「計画を立てる」話題を出す
- **投稿しないもの**：APIキー、環境変数、メールアドレス、本名などが写り込んだ画像。未リリースの機能を「できる」と書くこと

## 投稿の型

```
〇〇ができるようになりました。
（何が便利になるかを一言）
（学んだこと・詰まったことを一言）
#個人開発
```
